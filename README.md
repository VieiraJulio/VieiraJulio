<details>
<summary><b>🏗️ Data Engineering</b> — <i>building data lakes, data warehouses and pipelines that deliver trusted data</i></summary>

<br>

**What I do**
- Design **data architectures** with **Data Lake**, **Lakehouse** and **Data Warehouse** layers on **Microsoft Fabric**
- Build **ETL / ELT** pipelines with Fabric Pipelines, Mirroring and Notebooks
- Process and transform large datasets with **Python** and **PySpark**
- Integrate **multiple data sources** (databases, files and **APIs**) into a single consolidated model
- Ingest data from **REST APIs** with Python
- Apply **data governance**: access control, permissions, security and documentation across the lakehouse and warehouse
- Organize data in layers (bronze, silver and gold) following the **medallion architecture**
- Model data for analytics: fact and dimension tables, **star schema**, clean and documented
- Store data in columnar formats such as **Delta** and **Parquet**
- Build incremental loads and validate data quality between source and destination
- Version and ship work with **Git**
